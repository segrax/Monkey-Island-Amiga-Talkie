# Amiga Workbench icon

`runtime/MonkeyTalkie.info` is the unmodified `Monkey_Island.info` extracted
from the original disk 1 ADF supplied for development. It contains the classic
Monkey Island title artwork and both normal and selected Workbench images.
The builder writes it beside the Amiga `MonkeyTalkie` executable, using the
matching filename required by Workbench.

SHA-256: `70eb8b553340bb6e9d7c094a0e072e9d9d1d13d59c3a3a37ab7c30c96d7a61a1`.
